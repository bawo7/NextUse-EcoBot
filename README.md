♻️ NextUse — EcoBot

EcoBot is an AI-powered recycling assistant built into the NextUse application. It helps users make better environmental decisions by answering everyday waste disposal questions in a simple, conversational way.

Instead of guessing where your waste goes, EcoBot tells you exactly which bin to use, how to prepare items, and why it matters.

🌍 Project Overview

NextUse is designed to contribute to UN Sustainable Development Goal 13: Climate Action by addressing one of the most overlooked drivers of environmental harm — improper waste disposal.

EcoBot plays a key role in this mission.

It acts as a smart, accessible guide that simplifies recycling for everyday users. Rather than relying on confusing guidelines or inconsistent rules, users can just ask EcoBot questions in plain language and get instant, reliable answers.

🚀 What EcoBot Does

EcoBot focuses on four core areas:

♻️ Waste Sorting
Identifies the correct bin:
Recycling
Compost/Organic
General waste
Hazardous waste

🧼 Preparation Guidance
Explains how to properly prepare items before disposal:
Rinse containers
Remove labels
Flatten packaging

📚 Recycling Education
Teaches users:
Plastic recycling codes (1–7)
Recycling symbols
Contamination and why it matters

🌱 Eco-Friendly Tips
Recommends practical habits:
Reduce single-use plastics
Reuse everyday items
Choose sustainable alternatives

💡 Why This Project Matters

Climate change is one of the most urgent global challenges today, and waste management plays a direct role in it.

Landfills produce methane, a greenhouse gas more potent than CO₂
Misplaced recyclables often end up in landfills
Contaminated recycling can cause entire batches to be discarded

The real issue isn’t lack of awareness — it’s confusion.

Recycling rules are:

Inconsistent
Hard to remember
Different across locations

EcoBot solves this by making the right choice the easiest one.

With instant, personalized guidance, users can confidently dispose of waste correctly — contributing to climate action in small but meaningful ways.

🧠 How EcoBot Works

EcoBot uses an AI model guided by structured instructions to ensure responses are:

Clear and easy to understand
Friendly and conversational
Accurate and helpful
Process Flow:
User asks a question (e.g., “Where do I throw a plastic bottle?”)
EcoBot processes the request using its trained prompt system
User receives:
Correct bin recommendation
Explanation
Optional eco tip

EcoBot also:

Remembers conversation context during a session
Stores past conversations locally for future reference
⚙️ Tech Stack
Backend: Node.js
AI Engine: Groq API (LLaMA model)
Language: JavaScript
🛠️ Getting Started
Requirements
Node.js
 (v18 or higher)
A free Groq API Key
Installation

1. Clone the repository

git clone https://github.com/bawo7/NextUse-Ecobot.git
cd NextUse-Ecobot

2. Install dependencies

npm install

3. Add your API key

Create a .env file in the root directory:

GROQ_API_KEY=your_api_key_here

4. Run the application

node index.js
💬 Example Interaction
🤖 EcoBot: Hi! I'm EcoBot, your recycling assistant. What would you 
            like help disposing of today?

👤 You: Can I recycle a plastic bag?

🤖 EcoBot: Plastic bags should NOT go in your home recycling bin — they can jam
            sorting machines. Take them to a supermarket drop-off point instead.
            Better yet, switch to reusable bags!
